# Agent runtime standards

The invariants the agentctl fleet holds, one per line with its why and the test that fails when it breaks. The global rules link here; the shape is in `~/.config/agentctl/ARCHITECTURE.md` and the state words in `fleet-states.md` beside this file.

- A headless model run goes through `agentctl-run`, never `claude -p` directly. Why: only `agentctl-run` applies the role (what it may do) and the route (which model and endpoint), so a direct call silently inherits whatever the calling shell has. Test: `tests/unit/runner_contract.bats` "nothing in the repo launches a headless claude except agentctl-run".
- A runner ends every pass with one `last-outcome` word from `WORKED NOOP BLOCKED FAILED STALLED`, written by `proof_report` or `proof_verdict` in `agent-proof.sh`. Why: `fleet-liveness` and the KPI table read that word, and a free-text verdict (delivery-loop's old FAILED) was invisible to both. Test: `tests/unit/agent_proof.bats` "proof_report records a word outside the vocabulary as FAILED, naming it".
- A session's bucket is computed once, by `fleet-sessions --write` into `~/.local/state/fleet/state.json`, and every view renders that document instead of recomputing it. Why: nine readers in eight vocabularies disagreed about the same session. Tests: `tests/unit/fleet_sessions.bats` "--write: the state document holds the --json rows, their activity, and pending asks"; `tests/integ/agent_mqtt_publish.bats` "each session carries its bucket from the fleet state document, joined by target".
- Runners, timers and direct headless launches may only shrink: to add one, retire one or raise `~/.config/agentctl/ledger-baseline` with a why in the same PR. Why: each new need had become a new script and timer, and nothing counted them. Test: `tests/unit/consolidation_ledger.bats`, and `fleet-bench ledger --check` on the daily scorecard.
- Session quality is what `agentctl-session-outcomes` counts and `fleet-bench kpi` reports; no model scores a transcript. Why: the per-Stop judge failed on 59% of turns over 30 days and scored 10/10 on 78% of the rest, so nothing could act on it. Test: `tests/integ/stop_hook_quiet.bats` "no post script calls a model".
